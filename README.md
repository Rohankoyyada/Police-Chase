# 🚔 Police Chase

A 3D police chase game developed using **Unity and C#**, where players take control of a police vehicle, chase down militants, and complete missions to protect the city.

## 🎮 About the Project

Police Chase is a 3D driving and action game focused on vehicle control, police pursuit mechanics, and mission-based gameplay.

The player takes the role of a police officer responsible for stopping militants before they blast the city. Players must navigate through the city, locate targets using the mini-map, chase them down, and eliminate threats within the given time.

## ✨ Features

- **Vehicle Controls:** Police vehicle movement, steering, and driving mechanics.
- **Police Chase System:** Chase and pursue criminal vehicles.
- **NPC Vehicle System:** AI-controlled vehicles.
- **Mini-map System:** Displays target locations.
- **Mission System:** Mission objectives and countdown timer.
- **Kill Counter:** Tracks eliminated targets.
- **Collision Detection:** Detects interactions between game objects.
- **Object Pooling:** Reuses vehicle objects to improve performance.
- **Game UI:** Start panel, mission panel, game-over screen, and restart functionality.

## ⚙️ How to Run the Project

1. Clone this repository.
2. Open Unity Hub.
3. Click **Add Project from Disk**.
4. Select the downloaded project folder.
5. Open the project using its compatible Unity version.
6. Open the main game scene.
7. Press Play to start playing.
